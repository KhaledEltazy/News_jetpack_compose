# News App

A Jetpack Compose-based news application implementing Clean Architecture.

## Features

- Jetpack Compose UI
- MVVM architecture
- Clean Architecture (data, domain, presentation layers)
- Paging 3 for pagination
- Retrofit for network requests
- Room for local caching
- DataStore Preferences for local data storage
- Dagger Hilt for dependency injection

## Based On

This application was built by following the course by Mohamed Nawas on the LandOfCoding YouTube channel.
